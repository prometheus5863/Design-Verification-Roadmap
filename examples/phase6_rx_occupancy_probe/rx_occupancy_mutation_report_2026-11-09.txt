--------------------------------------------------------------
FINDING 2 -- K2 IS THE DISCRIMINATOR, and it is a set membership
            question rather than a first-failure one
--------------------------------------------------------------

  The claim under test: the pop-effect check K2 fires for BOTH wire
  mutants -- R4 (rx_pop late) and R5 (rx_pop never) -- and for no
  decode-only mutant, in both probe configurations.
  Both halves are required.  A check that fires for everything
  discriminates nothing.
  B  R4  K2 PRESENT   (a wire mutation changed DUT behaviour)
  B  R5  K2 PRESENT   (a wire mutation changed DUT behaviour)
  B  R1  K2 absent    (decode only: the datapath is intact)
  B  R2  K2 absent    (decode only: the datapath is intact)
  B  R3  K2 absent    (decode only: the datapath is intact)
  C  R4  K2 PRESENT   (a wire mutation changed DUT behaviour)
  C  R5  K2 PRESENT   (a wire mutation changed DUT behaviour)
  C  R1  K2 absent    (decode only: the datapath is intact)
  C  R2  K2 absent    (decode only: the datapath is intact)
  C  R3  K2 absent    (decode only: the datapath is intact)

  DISCHARGED.  K2 separates 'the sequencing gate lied' from 'the DUT
  changed', which is exactly what the 11-07 report said was missing.

  TWO mechanisms, not one: R4 delays rx_pop and R5 removes it, and K2
  fires for both.  A check with one witness is a tripwire.

  AND THE SEPARATION SURVIVES THE ORDERING TRAP.  In configuration C
  the mutated wire trips K5 before K2, so R3 and R4 have the SAME
  first failing check there -- a first-failure report would have
  concluded the probe does not work.  Configuration B is the clean
  statement: with nothing checking STATUS at all, the three
  decode-only mutants ESCAPE and the wire mutant does not.

--------------------------------------------------------------
WHAT THIS DOES NOT ESTABLISH
--------------------------------------------------------------

  * The probe is WHITE-BOX.  K2 reads dut.rx_cnt and dut.rx_wptr, so it
    is unavailable to any bench restricted to the APB port, and it is
    not a substitute for the black-box checks -- it is an instrument for
    attributing their failures.
  * Configuration B's escapes are NOT a defect of the probe.  Nothing in
    B reads STATUS, so a STATUS-decode mutant has no observer by
    construction.  B is a negative control, not a coverage claim.
  * One stimulus shape.  This bench runs a single deterministic burst,
    not the 4-seed x 2-mode matrix of the 11-07 runner, so it measures
    the DISCRIMINATION and inherits nothing about seed sensitivity.
  * K5's own exercise is counted (V4) but its sampling is still tied to
    the drain loop's pace; at a wider divisor the FIFO is non-empty for
    a smaller fraction of the run, and V4 is what would notice.
