WHAT THIS MEASURES
--------------------------------------------------------------

  SYNC_ONLY is CONFIRMED for STATUS.rx_avail, and the census's
  exposure argument is now a measurement.  Every mutant is caught,
  none by a check naming the signal -- which is exactly what
  'read to sequence, never checked, but not unexposed' means.

  R4 is deliberately uninformative about the classification.  rx_pop
  gates on rx_avail, so mutating the WIRE stops the RTL popping the
  last byte: a detection there is the data path noticing the DUT
  changed, not the bench noticing its sequencing gate lied.  Had the
  matrix reported only DETECTED, this row would have read as a fourth
  success for a claim it never tested.

  AND R3 AND R4 ARE INDISTINGUISHABLE IN THIS MATRIX.  Both report the
  same first failing check with the same byte count, because both make
  the last byte unreadable -- R3 by stopping the bench asking for it,
  R4 by stopping the RTL popping it.  The mechanisms differ and this
  instrument cannot tell them apart, which bounds what the control
  establishes: it shows a wire mutation is detected, not that it is
  detected DIFFERENTLY.  Separating them needs a check that observes
  rx_cnt directly, and that is logged rather than claimed here.
