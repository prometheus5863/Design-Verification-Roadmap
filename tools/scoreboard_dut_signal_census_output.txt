SECTION 4.  C4 -- DISCRIMINATING POWER
------------------------------------------------------------------------------
  AMENDED 2026-10-12, the same session this control was written,
  and the amendment is the interesting part.  C4 was first phrased
  as "the census must contain at least one TRUSTED row", on the
  2026-10-08 argument that a census reporting itself clean has no
  power to find anything.  That phrasing BROKE THE MOMENT THE
  DEFECT WAS FIXED: repairing the one TRUSTED row the census found
  made the control fail, so as written it REQUIRED A DEFECT TO
  EXIST.  A control must not demand that the thing it looks for
  still be there.

  The right question is not whether a defect is present now but
  whether this census has EVER been shown to find one.  So C4 now
  requires at least one row carrying a DEMONSTRATED ESCAPE: a
  mutant that was actually run against the pre-repair code and
  survived it.  That property is permanent, and it is the inverse
  of 2026-10-08's rule -- a control with no control is useless, and
  so is one that cannot pass on healthy code.

       only the controls are mechanical.  A row declared PREDICTED
       that is really TRUSTED passes every control here, and the
       only thing that would catch it is running its mutant.
    2. That the file list is complete.  5 files are censused;
       the repository has more checkers than that, and C2 is
       complete only WITHIN a censused file.  Adding a file can
       only add rows, never remove them.

       signal is observable by this checker, not that the
       prediction itself is right.
